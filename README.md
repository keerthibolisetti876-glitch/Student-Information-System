# 🎓 Student Information System

## 📌 Project Overview

Student Information System is a web-based application developed as part of the DataAlcott Web Development Internship.

The system provides a simple and organized way to manage student information, academic records, attendance, fees, documents and reports.

## 🎯 Objective

The main objective of this project is to create a responsive and user-friendly Student Information System for managing student data efficiently.

## ✨ Features

- 📊 Dashboard with student statistics
- 👤 Student Profile
- 📝 Student Registration
- 👥 Student Listing
- 🔎 Student Search
- 📚 Academic Records
- 📅 Attendance Records
- 💰 Fee Management
- 📄 Student Documents
- 📊 Reports
- 🔐 Login/Register interface
- 📱 Responsive design for mobile and desktop
- ⚡ JavaScript-based interactivity

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages
